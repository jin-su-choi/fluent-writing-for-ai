# Fluent Writing for AI

[English](README.md) | [한국어](README.ko.md)

AI가 조사·분석·구현 결과를 읽는 사람이 이해하고 검토할 수 있는 문서로 정리하도록 돕는 글쓰기 스킬입니다.

핵심 원칙은 **독자가 무엇을 이해하고 판단하거나 실행해야 하는지를 기준으로 정보를 고르고 구성하는 것**입니다.

## 활용 목적

- **타인과 공유할 문서:** 작업에 참여하지 않은 동료에게 전달하는 보고서, 제안서, 설계 문서, 인수인계 문서
- **AI의 작업을 직접 검토할 문서:** 대화를 다시 읽거나 중간 작업을 일일이 확인하지 않아도 AI의 조사 결과, 방법, 판단 근거를 검토할 수 있는 문서

두 경우 모두 문서만으로 결과를 이해하고 평가할 수 있도록 필요한 배경·방법·근거·조건을 함께 제시합니다.

## 스킬 목록

| 스킬 | 내용 |
|---|---|
| [fluent-english](skills/fluent-english/SKILL.md) | 독자 중심의 영어 문서 작성과 수정 |
| [fluent-korean](skills/fluent-korean/SKILL.md) | 공통 글쓰기 원칙과 자연스러운 한국어 문장·용어 지침 |

문서 작성·교정에 적용하며, 채팅에 쓰는 문서 초안도 포함합니다. 일반 대화, 단순 질의응답, 작업 진행 안내에는 언어가 같다는 이유만으로 적용하지 않습니다.

## 글쓰기 철학

- **독자의 목적에 맞는 정보 선택:** 독자가 결과를 이해하고 판단하거나 활용하는 데 필요한 내용을 고릅니다.
- **최종 결과를 중심으로 한 구성:** 현재 유효한 사실과 가설·폐기된 안을 구분하고, 조사 순서나 자료 파일별 구분을 목차로 옮기지 않습니다.
- **근거와 설명 목적에 맞는 관계:** 비교·대립·분류·단계·역할 분담은 실제로 필요할 때 사용합니다.
  - 한 문장에서도 그럴듯한 구도를 만들기 위해 관계를 덧붙이거나 내용을 끼워 맞추지 않습니다.
- **의미를 유지하는 간결함:** 주장의 뜻을 결정하는 범위·조건·불확실성·근거를 함께 설명합니다.
- **문서 전체에 통합하는 수정:** 피드백을 해당 주제의 기존 본문에 반영하고 요약·결론·표도 함께 갱신합니다.

## 핵심 작성 방법

### 작업 경과를 뺀 초안 검토

여러 시행착오를 거친 작업을 문서로 정리할 때 사용합니다.

1. 초안에서 조사·실험·구현 경과와 검토했던 대안을 임시로 뺍니다.
2. 작업을 모르는 독자의 입장에서 읽고, 결과와 방법을 이해하거나 판단하는 데 부족한 설명을 찾습니다.
3. 필요한 설명만 독자가 읽어야 할 위치에 넣습니다.

핵심 주장을 뒷받침하는 증거와 조건은 남깁니다. 들인 노력이나 줄어든 분량을 이유로 경과 설명 전체를 다시 넣지 않습니다.

### 필요한 위치의 설명

- 내용을 이해하는 데 필요한 전제는 먼저 설명합니다.
- 주장의 범위와 조건은 해당 주장에 붙여, 접힌 상세를 열지 않아도 뜻을 이해할 수 있게 합니다.
- 같은 판단에 필요한 근거와 비교 대상을 함께 놓아 독자가 여러 곳의 정보를 조합하지 않아도 되게 합니다.

### 내용에 맞는 문서 형식

- 소제목은 내용을 가리키는 짧은 명사구로 씁니다.
- 항목별로 확인할 사실·조건·절차는 목록으로, 인과관계를 이어 설명할 내용은 문단으로 씁니다.
- 불렛에는 핵심 내용을 두고, 딸린 조건·예외·예시는 서브 불렛으로 나눕니다.
- 표와 토글은 정보의 관계를 이해하거나 세부 내용을 확인하는 데 도움이 될 때 사용합니다.

정해진 목차나 문장 수를 강제하지 않으며, 정보의 관계에 맞게 조정합니다.

## 줄이려는 AI의 한국어 표현 습관

한국어판은 정보 구성과 함께 문장·용어의 자연스러움도 다룹니다.

| 반복되는 문제 | 작성 기준 |
|---|---|
| 뜻을 짐작할 수 있다는 이유로 ‘설명이 넓다’ 같은 낯선 단어 조합을 사용 | 실제 행위와 결과에 맞는 통용어와 구체적인 서술어 선택 |
| 영어 표현이나 기술 용어를 어색한 한국어로 풀어 옮김 | 정착된 번역어나 음차를 사용하고, 적절한 표현이 없으면 원어 유지 |
| 간결하게 쓰려다 필요한 조사·어미·문장 성분을 생략 | 대상과 조건이 분명한 완결된 문장으로 작성 |
| 명사화·피동·긴 수식어를 겹쳐 뜻을 흐림 | 실제로 무엇이 어떻게 되는지 드러나도록 필요한 부분을 수정 |
| 반복을 피하려고 익숙한 표현이나 종결어미를 기계적으로 바꿈 | 자연스러운 표현을 유지하고 불필요한 변형을 피함 |

문장을 다듬을 때도 사실, 조건, 가능성, 유보의 정도는 그대로 유지합니다.

## 설치

Codex에서 기본 제공 스킬 설치 도구에 다음과 같이 요청합니다. 필요한 스킬 하나만 지정해도 됩니다.

```text
$skill-installer를 사용해 jin-su-choi/fluent-writing-for-ai 저장소의
skills/fluent-english와 skills/fluent-korean을 설치해줘.
```

GitHub 저장소의 스킬 설치를 지원합니다. [Codex 설치 안내](https://learn.chatgpt.com/docs/build-skills#install-curated-skills-for-local-use)에서 확인할 수 있습니다.

## 사용 예시

```text
$fluent-korean
지금까지의 분석 결과를 작업에 참여하지 않은 동료가 읽을 보고서로 정리해줘.
결과와 방법, 판단에 필요한 근거를 포함해줘.
```

영어 문서에는 `$fluent-english`를 사용합니다. 각 스킬 폴더의 `SKILL.md`에는 작성 지침이, `agents/openai.yaml`에는 Codex용 표시 정보가 들어 있습니다.
