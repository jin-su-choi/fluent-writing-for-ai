# Fluent Writing for AI

[English](README.md) | [한국어](README.ko.md)

AI가 작성하는 공유 문서와 작업 검토 문서를 위한 글쓰기 스킬입니다. 독자가 이해하고 판단하는 데 필요한 정보를 고르고, 설명 순서와 근거·조건을 함께 정리하도록 안내합니다.

## 활용 목적

- **타인과 공유할 문서:** 작업에 참여하지 않은 동료에게 전달하는 보고서, 제안서, 설계 문서, 인수인계 문서
- **AI의 작업을 직접 검토할 문서:** 대화를 다시 읽거나 중간 작업을 일일이 확인하지 않아도 AI의 조사 결과, 방법, 판단 근거를 검토할 수 있는 문서

## 글쓰기 철학

독자가 알아야 할 내용을 기준으로 정보를 고르고 설명 순서를 정합니다. 두 스킬 모두 아래 작성 습관을 개선하는 데 초점을 맞춥니다.

| 문제가 된 AI의 습관 | 작성 기준 |
|---|---|
| 조사하고 수정한 순서대로 보고서를 구성 | 최종적으로 설명할 대상을 중심으로 내용을 다시 고르고 독자의 이해 순서에 맞게 배치 |
| 작성자만 아는 배경을 전제로 설명 | 독자의 사전지식과 앞서 읽은 내용만으로 이해되는지 확인하고 필요한 전제를 먼저 설명 |
| 그럴듯한 비교·대립·분류·역할을 만들어 붙임 | 관계의 근거와 설명상 필요성을 확인하고 대상의 기능·행동을 직접 설명 |
| ‘A가 아니라 B’처럼 불필요한 대조로 강조 | 필요한 내용을 긍정문으로 바로 전달하고 구분이 중요할 때만 대조 사용 |
| 피드백을 ‘추가 설명’ 섹션에 계속 덧붙임 | 해당 주제의 기존 본문에 통합하고 요약·결론·표도 함께 갱신 |
| 중요한 조건을 뒤로 보내거나 토글 안에 숨김 | 주장의 뜻을 결정하는 범위와 조건을 해당 주장과 함께 본문에 제시 |
| 한 불렛에 여러 조건과 부연을 몰아넣음 | 공통 주제와 세부 사항을 구분하고 적절한 서브 불렛 사용 |
| 구성 문제를 문장 다듬기나 표 변환으로 해결하려 함 | 정보 선택과 설명 순서부터 점검한 뒤 표현과 형식을 수정 |

내용을 줄이거나 수정할 때도 사실·수치·범위·불확실성·판단 근거는 그대로 유지합니다.

## 핵심 작성 방법

### 작업 경과를 뺀 초안 검토

여러 시행착오를 거친 작업을 공유하거나 검토할 문서를 작성할 때 사용합니다.

1. 초안에서 조사·실험·구현 경과와 검토했던 대안을 임시로 뺍니다.
2. 작업을 모르는 독자의 입장에서 읽고, 결과와 방법을 이해하거나 판단하는 데 부족한 설명을 찾습니다.
3. 필요한 설명만 독자가 읽어야 할 위치에 넣습니다.

핵심 주장을 뒷받침하는 증거와 조건은 남깁니다. 들인 노력이나 줄어든 분량을 이유로 경과 설명 전체를 다시 넣지 않습니다.

### 필요한 위치의 설명

- 내용을 이해하는 데 필요한 전제는 먼저 설명합니다.
- 주장의 범위와 조건은 해당 주장에 붙여, 접힌 상세를 열지 않아도 뜻을 이해할 수 있게 합니다.
- 같은 판단에 필요한 근거와 비교 대상을 함께 놓아 독자가 여러 곳의 정보를 조합하지 않아도 되게 합니다.

### 내용에 맞는 문서 형식

- 소제목은 내용을 가리키는 짧은 명사구로 씁니다.
- 항목별로 확인할 사실·조건·절차는 목록으로, 인과관계를 이어 설명할 내용은 문단으로 씁니다.
- 불렛에는 핵심 내용을 두고, 딸린 조건·예외·예시는 서브 불렛으로 나눕니다.
- 표와 토글은 정보의 관계를 이해하거나 세부 내용을 확인하는 데 도움이 될 때 사용합니다.

정해진 목차나 문장 수를 강제하지 않으며, 정보의 관계에 맞게 조정합니다.

## 줄이려는 AI의 한국어 표현 습관

한국어판에는 다음 [문장·용어 지침](skills/fluent-korean/SKILL.md#자연스러운-문장과-용어)이 추가로 들어 있습니다.

| 반복되는 문제 | 작성 기준 |
|---|---|
| 낯선 명사 조합이나 불필요한 비유로 뜻을 흐림 | 실제 행위와 결과를 정확히 가리키는 통용어와 구체적인 서술어를 우선 |
| 고유명사·기술 용어를 어색한 한국어로 풀어 옮김 | 정착된 번역어나 음차를 사용하고, 적절한 표현이 없으면 원어 유지 |
| 줄글에서 필요한 문장 성분·조사·어미를 생략 | 필요한 성분을 갖추고 서술어와 종결어미로 문장을 마무리 |
| 불필요한 ‘~의’, 뜻을 흐리는 명사화·피동·긴 수식어를 사용 | 의미가 불분명해진 부분을 중심으로 수정 |
| 연결어·종결어미를 기계적으로 바꾸거나 자연스러운 표현을 불필요하게 변형 | 문맥에 맞는 자연스러운 표현을 유지 |

문장을 다듬을 때도 사실, 조건, 가능성, 유보의 정도는 그대로 유지합니다.

## 설치

Codex에서 기본 제공 스킬 설치 도구에 다음과 같이 요청합니다. 필요한 스킬 하나만 지정해도 됩니다.

```text
$skill-installer를 사용해 jin-su-choi/fluent-writing-for-ai 저장소의
skills/fluent-english와 skills/fluent-korean을 설치해줘.
```

GitHub 저장소의 스킬 설치를 지원합니다. [Codex 설치 안내](https://learn.chatgpt.com/docs/build-skills#install-curated-skills-for-local-use)에서 확인할 수 있습니다.

## 사용 예시

```text
$fluent-korean
지금까지의 분석 결과를 작업에 참여하지 않은 동료가 읽을 보고서로 정리해줘.
결과와 방법, 판단에 필요한 근거를 포함해줘.
```

영어 문서에는 `$fluent-english`를 사용합니다. 각 스킬 폴더의 `SKILL.md`에는 작성 지침이, `agents/openai.yaml`에는 Codex용 표시 정보가 들어 있습니다.
